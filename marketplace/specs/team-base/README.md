# 项目规范

本目录是项目的开发规范，人和所有 AI Agent 都要遵守。内容来自公司的 `spec-templates` 仓库，安装后归本项目所有，可以按项目情况修改。

## 目录

| 目录 | 内容 |
|---|---|
| `shared/` | 所有项目通用：Git、测试、安全、AI 使用 |
| `guides/` | 开发指南：开始前、完成前、遇到问题时怎么做 |
| `backend/` | 后端规范（FastAPI 或 NestJS，按需安装） |
| `web/` | 网页前端规范（按需安装） |
| `miniapp/` | 微信小程序规范（按需安装） |
| `desktop/` | 桌面软件规范（按需安装） |

每个目录的 `index.md` 是入口，先读它。

## 维护规则

- 规范的改动走 PR，由模板负责人或技术负责人审查。
- 每条规则写清：要做什么、不要做什么、为什么，并尽量给出正确示例的文件路径。
- 能用 lint、测试或 CI 检查的规则，交给工具，不只写在这里。
- AI 或人反复犯同一个错误时，把规则补充到这里。
- 对所有项目都有用的改进，同步提交到公司的 `spec-templates` 仓库。

完整的团队流程见 `handbook` 仓库的《团队协作开发规范》。
