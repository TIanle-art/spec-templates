# 完成标准

一个任务同时满足以下条件，才算完成：

- [ ] 验收标准逐条满足
- [ ] 测试已补充，并且通过
- [ ] `make check` 通过，有真实的输出
- [ ] diff 中没有无关改动、调试代码、临时文件和密钥
- [ ] 数据库结构变化都有迁移
- [ ] 接口变化后，生成的类型已更新
- [ ] 文档、规格和规范已同步
- [ ] 高风险改动写明了回滚方案
- [ ] 过程中发现的遗留问题已建 Issue

## 提交 PR 时的说明

```markdown
## 改了什么

## 为什么改
Closes #

## 如何验证
- [ ] make check：
- [ ] 手工验证：

## 风险级别
L1 / L2 / L3（L3 写回滚方案）

## 请审查人注意
```

没有运行的检查，明确写出来，不要声称已通过。
