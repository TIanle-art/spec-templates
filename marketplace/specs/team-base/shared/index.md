# 通用规范

所有项目、所有成员和所有 AI Agent 都要遵守。

| 文件 | 什么时候读 |
|---|---|
| [git.md](git.md) | 建分支、提交、开 PR 之前 |
| [testing.md](testing.md) | 写测试、判断测试是否足够时 |
| [security.md](security.md) | 处理密钥、用户数据、权限和外部输入时 |
| [ai-usage.md](ai-usage.md) | 使用 AI 编码工具时 |

## 最重要的规则

1. 没有验收标准，不开始写代码。
2. 不直接推送 `main`，所有改动通过 PR 合并。
3. 提交前运行 `make check`，并如实报告结果。
4. 不提交密钥和真实客户数据。
5. 不删除、跳过或放宽测试来通过检查。
