# 数据和接口

## 接口调用

- 接口调用使用 `packages/api-client` 生成的 SDK 和 TanStack Query 代码。`lib/` 中配置请求客户端，它负责附加令牌、刷新令牌和解析统一的错误格式。
- 服务端数据使用 TanStack Query 管理；只在确实需要时使用 Zustand 保存本地状态。
- 查询的 key 沿用生成代码的约定，修改数据后让相关的查询失效。
- 生成的 SDK 方法名来自后端的 `operationId`（`标签-函数名`）。后端改了函数名或标签，SDK 的方法名会变，重新生成后要一起修改调用处。
- 错误提示使用后端返回的 `message`；排查时记录 `request_id`。

## AI 流式输出

- 使用 SSE 接收 `delta`、`usage`、`error`、`done` 事件。
- 提供停止生成的按钮；停止时中断请求，后端会同步取消模型调用。
- 出错时保留已生成的内容，并提供重试。
- 达到用量上限时，显示明确的提示，不静默失败。
